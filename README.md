# Smart Measurement Lab - Math Year 5

Independent Math Year 5 edition generated from the shared Smart Measurement Lab source.

- Fixed curriculum level: Math Year 5
- Activities: limited to the existing textbook-aligned Year 5 measurement configuration
- Languages: Bahasa Melayu, Chinese, and English
- Input: mouse, touch, and keyboard friendly
- Teacher controls: values and units remain within the existing year-specific limits

The level selector is intentionally hidden in this edition. Shared interface and interaction
changes should be made in the source project and exported again so all editions stay consistent.
